# Instructions for Codex and other agents

This repository contains Riccardo Moz's long-form mathematics book on
operator algebras, the noncommutative torus, continued fractions, symbolic
dynamics, and finite-dimensional approximation.

Before doing any work in this repository:

1. Read this file completely.
2. Read `BOOK_CONTEXT.md` completely.
3. Read `OPEN_TASKS.md` completely.
4. Inspect the current version of `C_-algebras.tex`; the source file is the
   authority whenever an older chat summary disagrees with it.

## Files and repository

- Main source: `C_-algebras.tex`.
- Current compiled book: `C_-algebras.pdf`.

## Mathematical standard

- Treat the book as a serious mathematical monograph, not lecture-note
  shorthand.
- Check definitions, hypotheses, statements, proofs, notation, cross
  references, and dependence on earlier results.
- Give complete proofs when the user asks for a theorem to be included.
- Do not invent missing lemmas or attribute a result without checking it.
- If a source is ambiguous or appears wrong, verify it against the original
  source and, when appropriate, another authoritative source before changing
  the book.
- Prefer original papers and authoritative monographs. Local PDFs in
  `Biblio/` should be inspected before relying on recollection.
- Cite substantive borrowed results and constructions. Pure notation fixes,
  typographical corrections, and routine transcription repairs do not need a
  bibliography citation.
- If the text deliberately corrects a mathematical error in a source, say so
  precisely and cite the source. Do not accuse a source of error casually.
- Paraphrase sources except for short quotations; do not reproduce large
  copyrighted passages verbatim.

## Writing style

- The book is written in English.
- Match the existing formal, compact mathematical prose.
- Lead from definitions to lemmas, propositions, and theorems in a coherent
  order; do not leave a collection of disconnected observations.
- Use the established theorem environments and numbering.
- Avoid unnecessary headings, parenthetical clutter, and excessive physical
  motivation. Riccardo prefers mathematics over physics.
- Preserve deliberate concise notation. In particular, expressions such as
  denominators `2\epsilon` do not need additional parentheses.

## Established notation

- Crossed products are always written with the algebra first and the group
  second: `A\rtimes_\alpha G`.
- The noncommutative torus is the universal algebra generated by unitaries
  `U,V` satisfying
  `VU=e^{2\pi i\theta}UV`.
- Its crossed-product realization is
  `A_\theta\cong C(S^1)\rtimes_{\alpha_\theta}\mathbb Z`.
- Use `\widetilde A` for unitization. Do not use `A^+` for unitization,
  because superscript `+` is used for positive cones.
- Use `CA` and `SA` for the cone and suspension; never `C_A` or `S_A`.
- The book deliberately uses `C_C` for compactly supported continuous
  functions. Do not change it to `C_c` without explicit permission.
- Use `M_n(\mathbb C)` when the scalar field should be visible; omit it only
  when the surrounding convention makes the meaning unambiguous.
- For continued fractions in Part II, normally
  `\theta=[0;a_1,a_2,\ldots]\in(0,1)\setminus\mathbb Q`, with convergents
  `p_n/q_n`.
- The positive approximation errors are
  `\delta_n=(-1)^n(q_n\theta-p_n)>0`.
- The Effros--Shen algebra is denoted `\mathcal E_\theta`, not `A_\theta`.

## Verification after edits

For every meaningful source change:

1. Compile `C_-algebras.tex` with `pdflatex` or `latexmk` for enough passes to
   stabilize references and the table of contents.
2. Search the final log for errors, undefined references or citations,
   `Overfull`, and new `Underfull` warnings.
3. Render and visually inspect every changed PDF page when layout can matter.
4. Report exact source lines after the final edit, not stale line numbers from
   an earlier version.
5. Do not claim success merely because LaTeX returned exit code zero.

The currently accepted compilation state has no errors, undefined references,
or `Overfull` boxes. It has three older `Underfull \vbox` warnings on PDF pages
71, 88, and 89. Do not attribute these warnings to a new edit unless their
location or severity actually changes.
